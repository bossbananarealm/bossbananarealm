<h3 align="center">Small tools, sharp edges, no drama.</h3>

I build backend systems in Go and Python, mostly APIs and the plumbing that keeps microservices talking to each other without falling apart. Lately I've been spending a lot of time thinking about how to design data layers that actually age well — clean schemas, sensible caching with Redis, queries that don't make you wince six months later. There's something satisfying about getting the boundaries between services right, and I'm still figuring out where that line is.

#### About me

- 🔭 Reworking a FastAPI service layer to play nicer with PostgreSQL and Redis.
- 👯 Open to collaborating on open-source projects
- ⚡ Fun fact: I debug faster with music on
- 💬 Ask me about Go
